# OnDuty · 下班装死

一个只针对**工作软件**的安卓通知小工具：上班时正常提醒，下班 / 回家后自动收起工作 App 的通知，省去每天手动开关通知的麻烦。

> 名字有点损，功能很正经：**OnDuty** 是项目名，「下班装死」是桌面应用名——到点就对工作消息「装死」。

## 它做什么

- **时间窗 + 法定工作日**：内置 2026 / 2027 年国务院放假与调休安排，无需联网。
- **地点判据**：记录办公网 / 家庭网的网关与 DNS，连上即知在岗还是在家；不读 Wi-Fi 名称、不定位。
- **下班缓冲**：仍连办公网时，下班前 20 分钟照常提醒，20–60 分钟收起，满 60 分钟按加班放行；提前到岗标记「已抵达」。
- **休假模式**：设定起止时间，期间全部放行，到期自动恢复。
- **无声摘要**：收起通知后只留一条「已收起 N 条消息」，不含任何通知正文。

## 隐私与安全

这是本项目的核心设计目标：

- **零联网**：不申请 `INTERNET` 权限，物理上无法外传数据。
- **无定位**：不读 GPS / 经纬度，也不读 Wi-Fi 名称（SSID），只用网关与 DNS 认网络。
- **无存储读写**：数据只写应用私有目录，`allowBackup=false`，`adb backup` 也导不出。
- **无通讯录 / 短信 / 相机 / 录音 / 无障碍权限**；无第三方 SDK、无埋点、无崩溃上报。
- 通知正文从不落盘，摘要只记条数、时间与应用名。

权限白名单只有三项：通知使用权（必需）、`POST_NOTIFICATIONS`（无声摘要）、`ACCESS_NETWORK_STATE`（地点判据）。

## 安装

从 Releases 下载 `下班装死.apk`。需要 Android 13（API 33）及以上；已在 vivo X100S Pro、魅族 20（Android 16）上适配。

首次使用需授予「通知使用权」：打开应用 → 顶部提示卡「去开启」 → 系统设置中找到「下班装死」并打开。

> **从旧版升级请注意**：v2.1.0 旧版包名为 `com.shiftnotify.gate`，本仓库构建的包名为 `com.onduty.gate`，两者**不能覆盖安装**。请先卸载旧版，再安装新版；配置与通知授权需要重新设置。

vivo / 魅族用户建议在系统设置中允许自启动、后台运行、后台高耗电，并在最近任务里锁定应用，以保证判定服务不被清理。

完整说明见 [docs/安装与使用说明.md](docs/安装与使用说明.md)。

## 构建

需要 Android SDK（platforms/android-34、build-tools/36.0.0）、JDK 21，以及自备的签名 keystore。

```powershell
# 1. 把你的 keystore 放到 app/keystore/shiftnotify.jks
# 2. 设置签名口令（也可直接改 build.ps1 里的回退值）
$env:ONDUTY_KS_PASS = "你的口令"
# 3. 构建，产物输出到仓库根目录的 下班装死.apk
& ".\app\build.ps1"
```

工程为纯 framework API，无第三方依赖，可离线构建。`build.ps1` 已带 UTF-8 BOM；工程路径建议保持英文，避免 PowerShell 5.1 向原生工具传中文路径时乱码。

> 签名密钥 `app/keystore/*.jks` 与口令**不在仓库中**，请自备并妥善保管。

## 项目结构

```
OnDuty/
├─ app/                       Android 工程（源码 + 资源 + 构建脚本）
│  ├─ src/com/onduty/gate/    判定逻辑、通知监听、网络指纹、节假日表
│  ├─ res/                    布局、颜色、图标、动画
│  ├─ AndroidManifest.xml
│  └─ build.ps1               一键构建脚本
└─ docs/
   ├─ DESIGN.md               功能与安全权限设计
   └─ 安装与使用说明.md        用户手册
```

判定规则全部集中在 `app/src/com/onduty/gate/Guard.java`，优先级为：**休假 > 地点 > 时间窗 > 默认放行**，任何判据缺失都 fail-open 到放行。

## 已知局限

- 定向收起是「先收到再撤掉」，通知栏可能闪一下，提示音或振动可能已触发。
- 被撤掉的通知不会补发；系统级常驻通知（前台服务、安全提示）拦不住。
- 节假日只内置 2026、2027 两年，其他年份按周一至周五判定。
- 后台保活受厂商策略影响，无法保证 100% 准时。
