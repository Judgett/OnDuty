# 下班装死（OnDuty）v2.1.0 · 安装与使用说明

一个只针对**工作软件**的安卓通知小工具：上班时正常提醒，下班 / 回家后自动收起；不再需要每天手动去系统里开关通知。

- 安装包：`下班装死.apk`（66 KB，已签名）
- 版本：versionCode 4 / 2.1.0；minSdk 33（安卓 13+）/ targetSdk 34
- 包名为 `com.onduty.gate`。**注意：与旧版 `com.shiftnotify.gate` 包名不同，无法覆盖安装，需先卸载旧版再安装**（配置与通知授权需重新设置）
- 适配重点：vivo X100S Pro、魅族 20（均为安卓 16）；其他安卓 13+ 机型同理

---

## 本版改了什么

| 你的优化点 | 这一版的表现 |
|---|---|
| 去掉影院 / 会议场景 | 场景卡片、全局静默档全部移除。本应用只管工作软件通知，不碰其他应用 |
| 工作日与法定工作日合并，节假日内置 | 合并为「法定工作日」一个选项；直接内置 2026、2027 两年国务院公布的放假与调休安排，完全不联网 |
| 下班 1 小时仍连办公网 = 加班 | 顶部状态显示「放行中 · 加班中」，照常提醒；提前到公司连办公网显示「已抵达」，也照常提醒 |
| 时间窗加休假选项 | 「休假」与「法定工作日」「每天」并列；可选起始日期时间，默认持续 1 天（可选 2/3/7 天）；期间全部放行 |
| 长按删除网络绑定 | 办公 / 家庭网络都可以点按钮记录或覆盖，长按按钮删除绑定（带确认弹窗） |

另外修复了上一版发现的问题：首次安装不弹通知权限导致摘要不显示、Wi-Fi 掉线重连后约 12 分钟不认办公网、帮助文案与实际行为不符、构建脚本路径写死、备份泄露风险等。详见 `DESIGN.md` 第 8 节。

> **安全边界**：本应用**没有 `INTERNET` 权限**，完全不能联网——没有上传、统计、远程配置或广告 SDK。节假日表直接内置，不联网也能用。

## 一、安装与覆盖升级

1. 把 APK 传到手机（文件传输助手或数据线），点击安装。
2. vivo / 魅族会拦一次「未知来源」，按提示允许「文件管理 / 微信」安装未知应用；提示「未经安全检测」时选仍要继续（本地自签名包，正常现象）。
3. 已装旧版直接覆盖即可，配置会保留；签名证书不变。

## 二、首次配置（四步）

1. 打开应用，顶部红字提示卡 → 点 **去开启** → 系统「通知使用权」列表里找到「下班装死」并打开。这一步是必需的，否则读不到任何通知。
2. 首次打开会弹出系统通知权限请求，请允许 —— 这是「已收起 N 条消息」无声摘要需要的；拒绝的话功能照常，只是没有摘要。
3. 点 **接管应用** → 勾选你要管住的工作 App（可按名称或包名搜索）→ 右上角「完成」。
4. 设定上班时间窗（默认 09:00 → 18:00）和类别（默认「法定工作日」），再到公司 / 家里各点一次「记录当前网络」。

建议做一次后台保活设置（vivo / 魅族通用，做一次即可）：

- 设置 → 应用与权限 → 权限管理 → 下班装死 → 允许自启动、允许后台运行
- 电池 / 耗电管理 → 后台高耗电 → 允许
- 最近任务里把「下班装死」锁定，避免被一键清理

## 三、页面怎么读

顶部深绿渐变是**状态卡**：

- 大字：`放行中` / `定向静默`。后面跟着小字标记：`加班中` / `已抵达` / `休假中`（命中才显示）。
- 下面一行说明为什么这么判，例如「加班中 · 仍连办公网络，按上班放行」。
- 四枚胶囊：`时间窗`、`办公网`、`家庭网`、`休假`，命中哪个点亮哪个。

下面五张卡片：

| 卡片 | 作用 |
|---|---|
| 接管应用 | 多选要管住的工作 App；下方开关控制是否发无声摘要 |
| 上班时间窗 | 起止时刻 + 七个自定义星期点；三个预设：`法定工作日` / `休假` / `每天` |
| 地点判据 | 记录办公 / 家庭网络；显示当前网关与 DNS；冲突时红字提示；**长按记录按钮删除绑定** |
| 执行方式 | 总开关「启用自动判定」；关掉后所有通知照常提醒 |
| 运行诊断 | 网络类别与网关 DNS、地点状态与持续时间、切换确认倒计时、时间窗与今天是否上班、节假日数据来源、状态标记、最近 12 条事件 |

页脚「查看使用说明与局限」可弹出完整说明。

## 四、判定规则（优先级从高到低）

1. **休假**：开启后整段时间全部放行，优先级最高。
2. **地点**：连办公网视为上班（早到、加班都放行）；连家里网视为下班，收起；连其他 Wi-Fi 按时间窗判定；断 Wi-Fi 转为「地点未知」，按时间窗判定。
3. **时间窗**：法定工作日（含国务院放假日与调休补班日）内放行，窗外收起。
4. **默认**：放行。

任何判据拿不到数据、权限被撤销，都回到放行或时间窗，不会把你静音一整天。

**下班后一小时的休息规则（前提：仍连着办公网）**

| 时间 | 通知怎么处理 | 顶部显示 |
|---|---|---|
| 上班前提前连上办公网 | 照常提醒 | 放行中 · 已抵达 |
| 下班后 0–20 分钟 | 照常提醒（这段留给下班后还用办公软件联系的情况） | 放行中 · 休息中 |
| 下班后 20–60 分钟 | 收起目标 App 通知，发无声摘要 | 定向静默 · 休息中 |
| 下班满 60 分钟仍连办公网 | 照常提醒，视为加班 | 放行中 · 加班中 |

如果已经离开办公网（连家里或其他 Wi-Fi、断网），不适用上表，按下面的地点 / 时间窗规则处理。

**切换要不要等待（防抖）**

| 情形 | 等待 | 为什么 |
|---|---|---|
| 连上办公网 → 判为上班 | **无需等待，立即生效** | 正常只有坐到工位才会连办公网，连上就说明已开始上班；再等 2 分钟反而漏掉刚到岗的通知 |
| 连上家庭网 → 判为下班 | 连续 5 分钟 | 收起比放行更保守，宁可晚收几分钟，也不错收工作消息 |
| 断网 / 连上没记录过的 Wi-Fi | **立即**退出在岗 | 属于「明确不在岗」，直接改由时间窗判定 |

「运行诊断」里的「切换确认中：已持续 X 分钟」现在只会在等家庭网确认时出现；连办公网是秒级的，不需要倒计时。

## 五、节假日是怎么算的

节假日表**直接内置在安装包里，不联网**。选「法定工作日」时，App 用内置表判断今天是不是上班日。

- **2026 年**（国务院办公厅 2025-11-04 通知，国办发明电〔2025〕7 号）：元旦 1/1–1/3，春节 2/15–2/23，清明 4/4–4/6，劳动节 5/1–5/5，端午 6/19–6/21，中秋 9/25–9/27，国庆 10/1–10/7；补班 1/4、2/14、2/28、5/9、9/20、10/10。
- **2027 年**（国务院办公厅 2026-11-05 通知）：元旦 1/1–1/3，春节 2/5–2/13，清明 4/3–4/5，劳动节 5/1–5/5，端午 6/9，中秋 9/15，国庆 10/1–10/7；补班 1/31、2/14、5/8、9/26、10/9。
- **其他年份**：按周一至周五判定，诊断区会注明「XXXX 年未内置」，不会误用旧表。

「运行诊断」里会显示当前数据来源，例如「内置表 2027」。

## 六、休假怎么用

1. 在时间窗卡片点 **休假**。
2. 选择起始日期和时间（默认是现在），选择持续 1 / 2 / 3 / 7 天（默认 1 天），确定。
3. 期间所有通知正常提醒，顶部显示「休假中」，胶囊「休假」点亮。
4. 在「运行诊断」卡片点 **结束休假，恢复自动判定**，随时提前结束。结束后时间窗类别恢复为「法定工作日」。

## 七、地点判据怎么做的（不需要定位权限）

App 不申请任何位置权限，也拿不到 GPS。它做的是「网络指纹」：

- 在公司连着公司 Wi-Fi 时点 **记录当前网络**，保存网关地址与 DNS 列表；
- 家里同样记录一次；
- 之后只要「网关一致且 DNS 有交集」就认定为那张网；
- **长按**记录按钮可删除绑定，点击可以重新记录或覆盖。

指纹只写在手机本地，不含 SSID、不含坐标、不上传。若两处指纹撞车（网关与 DNS 完全一致），界面红字提示，地点判据自动失效并回落时间窗。

## 八、权限清单（这份清单是刻意的）

**只申请三项权限**：

| 权限 | 用途 | 是否必需 |
|---|---|---|
| 通知使用权（系统特殊授权） | 监听并撤回目标 App 的通知 | 必需 |
| `POST_NOTIFICATIONS` | 发「已收起 N 条消息」无声摘要 | 可拒绝，只是没有摘要 |
| `ACCESS_NETWORK_STATE` | 读取当前网关 / DNS 做地点判定 | 地点判据需要 |

**没有申请的安全相关权限**：

- **无 `INTERNET`** —— 完全不能联网，没有上传、统计、远程配置、广告 SDK；这是一个物理上无法外传数据的应用。
- **无定位** —— 不申请任何位置权限，不读 GPS / 经纬度，也不读 Wi-Fi 名称（SSID），只用网关与 DNS 认网络。
- **无存储读写** —— 不申请外部存储权限，全部数据只写在本应用私有目录；`allowBackup=false`，连 adb backup 也导不出。
- **无通讯录 / 短信 / 通话 / 相机 / 录音 / 无障碍 / 勿扰访问**，`QUERY_ALL_PACKAGES` 也没申请（用 `<queries>` 替代）。
- **无 root / ADB / Shizuku / Device Owner 依赖**。

通知正文从不落盘，只记条数、时间与应用名。这些数据只在手机本地，关机重启后也只留在这台设备上。

## 九、已知局限

1. **只能事后撤回**：通知使用权是先收到再撤掉，通知栏可能闪一下，提示音或振动可能已触发。
2. 被撤掉的通知不会补发；摘要只记条数与时间，不保存正文。
3. 系统级常驻通知（前台服务提示、安全提示）拦不住。
4. 节假日只内置 2026、2027 两年，其他年份按周一至周五判定，诊断区会如实标注「未内置」。
5. 后台保活受厂商策略影响，无法保证 100% 准时；本版未在真机跑过（本机无模拟器）。
6. 签名 keystore 与口令仅存本地，已从公开仓库中排除。请妥善保管，不要随包分发。

## 十、建议你先测这几件事

1. 首次打开是否弹出通知权限请求；让目标 App 在非工作时段来一条通知，看是否被收起、摘要是否出现。
2. 在公司连办公网后锁屏 3 秒再亮屏，看状态卡能否在 2–3 分钟内回到「办公网络」（P0-2 回归项）。
3. 把下班时间设成临近时刻，等过 1 小时后仍连办公网，看是否显示「加班中」且通知照常提醒。
4. 点「休假」选一个起始时间 + 1 天，看期间是否全部放行；点「结束休假」后是否恢复判定。
5. 长按办公 / 家庭「记录当前网络」删除绑定，再点一次重新绑定。
6. 换到第三张 Wi-Fi，看状态卡与诊断是否在几秒内变成「其他网络」。

任何一项不符合预期，把「运行诊断」里的文字发我，我照着改。

## 附录：构建（想自己改的话）

源码在 `app/` 目录，一键构建：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
& "D:\AI\AIWorkSpace\OnDuty\app\build.ps1"
```

- 工具链：`D:\Tools\AndroidSDK`（`platforms\android-34\android.jar`、`build-tools\36.0.0`），JDK 21 在 `D:\Tools\Java\jdk-21.0.12.1`。build-tools 34.0.0 的 d8 在本工程会崩，必须用 36.0.0。
- **路径说明**：工程根目录 `OnDuty/app` 为纯英文路径，PowerShell 5.1 向原生工具传参不会乱码。build.ps1 已带 UTF-8 BOM，因此输出文件名为中文（`下班装死.apk`）也能正确生成。若把工程放到中文路径下，需自行建立英文目录联接再构建。
- 版本号写在 `AndroidManifest.xml`（versionCode 4 / 2.1.0）；改版本要改清单，`aapt2 link` 的参数只在清单未声明时生效。
- 签名：`app\keystore\shiftnotify.jks`（已 gitignore，需自备）。证书 `CN=ShiftNotify, O=Local Build, C=CN`，SHA-256 `16A5FF7206B8DB87B27531C832566D52F1518C5813580A32E91F22E69CF1F939`。**换签名会导致无法覆盖安装，升级已有安装时必须沿用原 keystore。**
- 口令不写入公开文档：本地构建者请自己在 `app/build.ps1` 的 `--ks-pass` / `--key-pass` 处填写，或从私有渠道获取。自行签发时 alias / 口令可与脚本默认值不同，改脚本对应行即可。
- 产物覆盖 `下班装死.apk`（在 `app/` 的上一级目录）。
